# HOM 3×4 매크로 패드 (핸드와이어드, 다이오드 없음)

- 키 12개 (3행 × 4열), 노브 없음
- 컨트롤러: RP2040 Pro Micro (USB-C) 1개
- 배선: **다이렉트 핀** 방식. 스위치마다 컨트롤러 핀을 하나씩 쓰기 때문에 다이오드가 필요 없습니다.
- 펌웨어: QMK + VIA (웹에서 키 변경 가능)

배선도: `docs/wiring.png`

## 배선 규칙 (딱 두 가지)
1. 모든 스위치의 **다리 하나**를 전선 하나로 이어서 컨트롤러의 **G(GND)** 핀에 연결합니다.
2. 각 스위치의 **나머지 다리**를 아래 표의 핀에 하나씩 연결합니다.

스위치는 방향(극성)이 없어서 두 다리 중 어느 쪽을 GND로 써도 됩니다.

| 앞에서 본 위치 | 1열 | 2열 | 3열 | 4열 |
|---|---|---|---|---|
| 1행 | K1 → **2** | K2 → **3** | K3 → **4** | K4 → **5** |
| 2행 | K5 → **6** | K6 → **7** | K7 → **8** | K8 → **9** |
| 3행 | K9 → **29** | K10 → **28** | K11 → **27** | K12 → **26** |

- 숫자는 보드에 인쇄된 핀 번호입니다 (GP2 = "2").
- **3V3, RST, 5V에는 아무것도 연결하지 마세요.**
- 판을 뒤집어서 납땜하면 **좌우가 바뀌어 보입니다.** 배선도 ②번 그림을 보세요.

## 펌웨어 올리기
1. BOOT 버튼(위쪽 버튼)을 누른 채로 RESET(아래쪽 버튼)을 눌렀다 떼고, BOOT를 뗍니다.
2. PC에 **RPI-RP2** 드라이브가 뜹니다.
3. `firmware/hom3x4_via.uf2` 파일을 그 드라이브에 **끌어다 놓습니다.**
4. 드라이브가 자동으로 사라지면 완료입니다.

조립한 뒤에 다시 업로드 모드로 들어가는 방법은 두 가지입니다.
- **K1을 누른 채로 USB를 꽂기**
- **Fn(K12)을 누른 채로 K1 누르기**

## 기본 키 배치 (Windows 기준)

| | 1열 | 2열 | 3열 | 4열 |
|---|---|---|---|---|
| 1행 | 복사 Ctrl+C | 붙여넣기 Ctrl+V | 잘라내기 Ctrl+X | 실행취소 Ctrl+Z |
| 2행 | 볼륨 − | 볼륨 + | 음소거 | 재생/정지 |
| 3행 | 저장 Ctrl+S | 찾기 Ctrl+F | 다시실행 Ctrl+Y | **Fn** |

Fn을 누르고 있을 때는 다음과 같습니다.

| | 1열 | 2열 | 3열 | 4열 |
|---|---|---|---|---|
| 1행 | 업로드 모드 | 1 | 2 | 3 |
| 2행 | 이전 곡 | 4 | 5 | 6 |
| 3행 | 다음 곡 | 7 | 8 | (Fn) |

## 키 바꾸기 (VIA)
1. 크롬이나 엣지 브라우저에서 https://usevia.app 에 접속합니다.
2. **Settings**에서 "Show Design tab"을 켭니다.
3. **Design** 탭에서 `firmware/hom3x4_via_definition.json`을 불러옵니다.
4. **Configure** 탭에서 키를 클릭하고 원하는 기능으로 바꾸면 바로 저장됩니다.

## 테스트 방법 (케이스에 넣기 전에)
펌웨어를 올린 뒤 메모장을 열고, **핀셋이나 전선으로 G 핀과 각 핀을 잠깐 붙여보세요.** 해당 키가 입력되면 정상입니다. 스위치를 납땜하기 전에 해보면 컨트롤러 불량 여부를 미리 알 수 있습니다.

## 펌웨어 소스
`qmk/hom3x4/`를 QMK의 `keyboards/handwired/hom3x4`에 복사한 뒤 빌드합니다.
```
qmk compile -kb handwired/hom3x4 -km via
```
빌드에 쓴 QMK 버전: `80973aa0` (2026-11-18)
