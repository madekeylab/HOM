# Keyball61 유선 빌드 부품 체크리스트

기준: 원작 빌드 가이드의 부품표 (`keyball61/doc/rev1/buildguide_en.md`). 키트 없이 PCB를 직접 주문하는 경우입니다.
펌웨어는 공식 QMK이고, 트랙볼 센서 드라이버는 `drivers/pmw3360`(**PMW3360**)입니다.

## 보유 / 주문 상태
- [x] RP2040 Pro Micro (USB-C) — **2개인지 확인**
- [ ] PCB 4종 (JLCPCB, `jlcpcb/` 폴더)
- [ ] 아크릴 판 (레이저 커팅, `acrylic/` 폴더)

## 공구
인두기 (온도 조절), 실납, 플럭스, 니퍼, 핀셋, 0번 십자 정밀 드라이버, 150방 정도의 사포

## 펌웨어
- RP2040은 **조립 전에** 먼저 펌웨어를 올리세요. BOOT 버튼을 누른 채 USB를 연결하면 RPI-RP2 드라이브가 뜹니다.
- 펌웨어는 [Keyball Link](https://keyball-link.shiroganelab.com/)에서 올립니다 (RP2040은 REMAP 미지원).
